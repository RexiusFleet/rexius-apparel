Test mode

Test items, employees and departments (marked Test in the Admin lists) stay out of check out, receiving, inventory, labels, activity and reports. Turn on test mode to use them: every screen switches over to test data only, so you can try receiving, invoice reading, labels, check out and reports without touching real numbers or real people. Anything you add while test mode is on is a test record. It applies to this browser tab only and switches off when you sign out or close the tab.

Sample test invoice

Clear test activity deletes every test transaction, test invoice and test vendor match, and sets the test items' cost back to $0.00, so the next round starts from zero. Test items, employees and departments are kept for next time.
